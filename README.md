Текст задачи
Дан текстовый файл с именем name, содержащий строковые представления целых чисел. Заполнить вектор V числами из исходного файла и вывести элементы вектора в исходном порядке.

Сигнатура функции:
bool fillFromFile (const std::string& name, std::vector<int>* v);

Алгоритм решения
Пользователь вводит имя файла. Функция fillFromFile открывает файл и создаёт вектор конструктором от двух итераторов: первый итератор istream_iterator<int> связан с файлом, второй (по умолчанию) обозначает конец данных. Если файл не открылся, в нём нет чисел или встретился не числовой символ (чтение не дошло до конца файла), программа пишет, что ввод неверный. Иначе элементы вектора выводятся в исходном порядке в цикле с итератором. При неверном вводе программа выводит Invalid input и запрашивает данные этой задачи заново, пока они не будут введены правильно.

Задание 2
Задача 2.6. Половины вектора и дека
Текст задачи
Даны вектор V и дек D, имеющие чётное количество элементов. Добавить в конец вектора первую половину элементов дека (в исходном порядке), а в начало дека — вторую половину исходных элементов вектора (в обратном порядке). Использовать два вызова функции-члена insert.
Сигнатура функции:
void addHalves (std::vector<int>* v, std::deque<int>* d);
Алгоритм решения
Пользователь вводит элементы вектора и дека (по одной строке для каждого), количество элементов должно быть чётным. Вектор заполняется через istream_iterator, дек создаётся конструктором от итераторов. Первый insert вставляет в конец вектора диапазон от d.begin() до d.begin() + d_half, где d_half — половина размера дека. После этого вектор изменился, и исходная вторая половина находится перед только что добавленными элементами. Поэтому вторым insert в начало дека вставляется диапазон обратных итераторов от v->rbegin() + d_half до v->rbegin() + d_half + v_half. Это вторая половина исходного вектора в обратном порядке. При неверном вводе программа выводит Invalid input и запрашивает данные этой задачи заново, пока они не будут введены правильно.

Задача 5.9. Дублирование набора положительных чисел
Текст задачи
Дано целое число K (> 0) и вектор V. Продублировать в векторе V первый набор из K подряд расположенных положительных чисел, вставив после этого набора его копию (если в наборе имеется больше K положительных чисел, то лишние числа во внимание не принимаются, и дублируется только начальная часть набора, содержащая K чисел). Если вектор не содержит требуемого набора чисел, то не изменять его. Использовать алгоритм search_n с параметром — функциональным объектом.
Сигнатура функции:
void duplicatePositive (std::vector<int>* v, int k);
Алгоритм решения
Пользователь вводит число K (K > 0) и элементы вектора. Алгоритм search_n с лямбда-выражением [](int x, int value) { return x > value; } и значением 0 ищет первые K подряд идущих положительных чисел. Если возвращённый итератор равен v->end(), вектор не меняется. Иначе создаётся копия диапазона от pos до pos + k, так как вставлять в вектор диапазон из него самого нельзя. Копия вставляется функцией insert сразу после набора, то есть в позицию pos + k. При неверном вводе программа выводит Invalid input и запрашивает данные этой задачи заново, пока они не будут введены правильно.

Задание 8
Задача 8.2. Пары соседних слов
Текст задачи
Дан список L, элементами которого являются английские слова. Получить дек D со строковыми элементами, каждый из которых строится по паре соседних элементов исходного списка L следующим образом: последняя буква правого элемента пары приписывается справа к первой букве левого элемента пары. Количество элементов дека D должно быть на 1 меньше количества элементов списка L. Например, для исходного списка ABC, DEF, KLM, XYZ полученный дек должен содержать строки AF, DM, KZ. Использовать алгоритм adjacent_difference с итератором вставки и функциональным объектом, а также функцию-член erase для дека D.
Сигнатура функции:
std::deque<std::string> makePairs (const std::list<std::string>& words);
Алгоритм решения
Пользователь вводит не менее двух слов в одной строке; список заполняется через istream_iterator<std::string>. Каждое слово должно состоять только из букв. Алгоритм adjacent_difference вызывает лямбда-выражение для каждой пары, передавая правый элемент первым параметром и левый вторым. Лямбда возвращает первую букву левого слова, к которой справа дописана последняя буква правого слова. Результат записывается в дек через back_inserter. Первый элемент алгоритм копирует без изменений, поэтому после вызова он удаляется функцией D.erase(D.begin()). При неверном вводе программа выводит Invalid input и запрашивает данные этой задачи заново, пока они не будут введены правильно.

Задание 10
Задача 10.1. Подсчёт повторений элементов
Текст задачи
Дан вектор V. Определить количество повторений каждого числа в векторе V и вывести все различные элементы вектора V вместе с количеством их повторений (в порядке возрастания значений элементов); количество повторений выводить сразу после значения соответствующего элемента. Использовать вспомогательное отображение M (класс map), ключами которого являются различные элементы вектора V, а значениями — количество повторений этих элементов. При заполнении отображения M не использовать условные конструкции (достаточно операций индексирования [] и инкремента). Элементы вектора V (при заполнении отображения M) и элементы отображения M (при выводе полученных результатов) перебирать в цикле с параметром-итератором соответствующего контейнера.
Сигнатура функции:
std::map<int, int> countRepeats (const std::vector<int>& v);
Алгоритм решения
Пользователь вводит элементы вектора. Функция countRepeats перебирает вектор циклом с итератором и для каждого элемента выполняет m[*i]++. Если ключа в отображении ещё нет, оператор [] создаёт его со значением 0, поэтому условия не нужны. Затем отображение выводится циклом с итератором: i->first — элемент, i->second — количество повторений. Так как map хранит ключи упорядоченно, элементы выводятся по возрастанию. При неверном вводе программа выводит Invalid input и запрашивает данные этой задачи заново, пока они не будут введены правильно.
